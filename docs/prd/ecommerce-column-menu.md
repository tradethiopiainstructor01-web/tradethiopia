# eCommerce outreach column menu

Sales → eCommerce cold call and bulk sms supports removing columns from saved Cold Call and Bulk SMS tables. Right-click a column heading, use Shift+F10 on its actions button, or click/tap the three-dot button; choose **Delete column**. The column disappears after the save succeeds. At least one column must remain visible.

Removal persists per saved table and signed-in owner. **Restore columns** lists removed columns and restores their original values. This is a reversible removal from the view: original headers and cell values stay stored. Removed columns are excluded from the displayed table, Excel export, row editor and SMS phone-column selector. Search still includes all stored columns. Imports retain their original layout and duplicate checks; repeating an import does not restore removed columns. Unsaved reference templates and import previews have no column actions.

A failed or stale save leaves the current view intact and reports an error; refresh before retrying a stale revision. The Cold Call and Bulk SMS tables remain separate.
